# DMS vs Tally Reconciliation

Upload one or many Excel/CSV files on each side, pick which voucher types to include, then reconcile. Files never leave your browser.

## Matching rules

Amount tolerance ₹ Date tolerance (days) [x] Fuzzy match leftovers (amount + date, ignore voucher no.) Fuzzy ± days [x] Fuzzy must be same type [ ] Ignore voucher prefix/leading zeros (match on trailing digits)
