Incentive Report Tool

Upload your incentive Excel (optional), the Tally ledger PDFs and the deal-sheet screenshots. Everything is processed inside your browser, and no file leaves your device.

1. Incentive Excel (optional)

No file. A new sheet is built from your ledgers and screenshots.

2. Tally ledger PDFs

Name files after the customer. Put “Aftersales” in the name for aftersales ledgers.

3. Deal-sheet screenshots

Each screenshot (or PDF page) gets a row below for you to check and type its values.

Deal-sheet values

Click a thumbnail to enlarge it, then check or type the VIN, VCPL discount and Total Retained Margin shown on it. For PDFs the tool tries to read the VIN, customer and margin itself, so please verify those. Leave a value blank if the sheet is empty, and it will be flagged as missing instead of guessed.

Or paste instead of uploading

Copy and paste works everywhere on this page. Press Ctrl+V to paste a screenshot or a copied file anywhere outside a text box (images go to deal sheets, PDFs to ledgers). The boxes below take pasted text.

Paste the incentive list from Excel

Copy the cells in Excel, including the header row (VIN, Delivered To, Sold By …), and paste here. Used only when no Excel file is uploaded.

Advanced rules

Extra ledger keywords, one per line as field=regex, for example accessories=GA sale|accessory. Fields: car_sale, tcs, road_tax, fastag, ew, bsi, insurance, facilitation, trade_in, finance, dsa, acc_discount, accessories, booking, receipt. Your rules are checked first and are remembered on this device.

Click any value to correct it. Edited cells are written into the Excel and marked “Edited”.
